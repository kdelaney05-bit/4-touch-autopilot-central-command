The rules it runs on

Four things that never change

The customer stays on plain text

No portal, no app for them. They text a number they already know.

The customer never sees the inside lane

Notes and crew talk are ours. Marked, colored, and invisible to them.

Open by default

Anyone inside can read any customer’s file. The only private thing is a direct line between two people.

Nobody is pushed unless named

No feed. No noise. Your name on it, or you never hear about it.
